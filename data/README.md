# Seed data

Everything in this folder is synthetic. The names, villages, phone numbers,
clinicians, consultations and campaign figures were made up for the demo and
do not describe real people or real activity. Phone numbers use the
placeholder ranges +91 90000 and +91 91111.

The dashboards compute their numbers from these files (see `services/metrics.py`),
so the figures on screen describe this demo data only.
